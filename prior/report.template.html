零讀數的訊號來自區塊長度

把零讀數的列切成「建築內連續零讀數小時的最大區塊」—— 這麼做是合法的，因為列在建築內 嚴格逐時且依時間排序（已驗證：連續列剛好前進 +1 小時的比例為 1.0000）—— 異常會集中在少數幾個 極長的區塊裡。14,466 個零讀數區塊中只有 718 個整段為異常， 卻裝了 78,450 個零讀數小時：全部 80,776 個零異常的 97.1%。

相對地，hour-of-day 在這裡幾乎沒用。24 個小時之間，零讀數列被標為異常的比例只在 45.7% 到 51.1% 之間移動 —— 全距 5.5 個百分點。 要分辨故障的 0 與合法的 0，可用的訊號是時序脈絡與區塊長度。

03

在可用的操作點上

固定閾值 0.50 在合併集上可比：兩個模型都標記 9–18% 的列，真實異常率 14.26%。 在兩個子集上，最佳閾值分別落在別處，且 F1 的絕對值不可跨半比較。

無技巧規則（標記每一列）得到 precision = 盛行率、recall = 1，即 F1₀ = 2π/(1+π)；隨機排序在前 r 比例切一刀得 2πr/(π+r)，對 r 遞增，故 F1₀ 即為無技巧上限。 這條基準隨盛行率劇烈變動，同一個 F1 值在兩半因而代表不同的技巧水準。

直接除以基準線（lift）的天花板為 1/F1₀， 在零讀數那半為 1.5×、在非零那半為 24×，兩者的可達範圍相差 16 倍。 可跨盛行率比較的量為上限固定於 1 的 skill score (F1 − F1₀)/(1 − F1₀)，或隨機恆為 0 的 MCC：

把 F1 放回基準線上（K = 725，Tree） 「無技巧 F1₀」= 全部標記所能得到的 F1。「lift 天花板」= 1/F1₀，即 lift 這個比值 在該盛行率下的最大可能值。F1 skill 與 MCC 的上限在任何盛行率下都是 1，隨機則分別為 0。 AP gain = (AP − π)/(1 − π)。
直覺上「零讀數 0.78 很好、非零 0.32 很差」的讀法是錯的；但反過來說「非零那半是基準的 11 倍所以更強」也是錯的 —— 那是拿一個最多 24× 的數字比一個最多 1.5× 的數字。 正規化之後兩半其實差不多：F1 skill 0.440 對 0.435，都走完了無技巧到完美之間約 44% 的路。 不同正規化會給出不同排序（lift 偏袒低盛行率、skill 與 MCC 較中性），這正是不該把它壓成單一數字的原因。 唯一在所有正規化下都一致的是：排除 building 1241 後的非零那半（skill 0.721 / MCC 0.734 / AP gain 0.733）與合併集一樣強，而含 1241 的版本（0.435 / 0.505 / 0.370）才是弱的那個。

0.50 的偏差源於平衡 context 的 prior shift

閾值偏差的來源在實驗設計：context 為 25,000 異常 / 25,000 正常，先驗 50%， 而評估資料的盛行率是合併 14.26%、非零那半 2.12%。此為標準的 prior shift， 其後果是分數系統性高估。K = 725 的校準情形如下：

校準：模型說的機率 vs 實際發生率 依分數分箱，箱內平均預測值對照箱內實際異常比例。已校準的分數會落在對角線上。 ECE 為各箱以列數加權的平均絕對偏差。
分數 0.5–0.6 那一箱，模型在非零子集上說 0.547，實際異常率是 0.030 —— 高估約 18 倍。這就是 0.50 一刀切下去 precision 崩掉的直接原因。 先驗換算也一致：50% 先驗下的分數要對應到 π 先驗的 0.5 後驗，原始分數得是 1−π —— 合併集 0.857、非零那半 0.979。實測 F1 最佳閾值（0.72 與 0.75）落在 0.50 與這兩個值之間， 位置正確，因為 F1 比 accuracy 容忍更多 false positive。 0.50 的偏差量因此由「平衡 context 訓練、不平衡資料評估」這個設計決定，屬於系統性偏差。 部署用的操作點需在驗證集重調，並按目標盛行率做先驗校正。

同樣的告警預算，不用閾值

標記的列數剛好等於真實異常數 —— 依分數取前 14.26%，此時 precision 等於 recall —— 就把閾值完全從比較裡移除。Tree 在每個 K 都領先，而 K = 725 的 +0.041 ± 0.005 約為 8.6 個標準誤，儘管該處合併 PR-AUC 只差 +0.008、 合併 ROC-AUC 甚至偏向 TabPFN。原因是排序最前段幾乎全是 reading = 0 的列。

04

合併後的 gap 從哪裡來

平均精確度可對兩半的正樣本做精確拆分，這份歸因因此是一個恆等式。

平均精確度等於「對每個正樣本，取其自身分數為閾值時所得的 precision，再取平均」。 依每個正樣本落在哪一半來拆這個平均，就得到一個精確分解，

AP = w₀·C₀ + wN·CN     w₀ = 80,776 / 90,691 = 0.8907    wN = 0.1093

從而也得到兩個模型差值的精確分解， ΔAP = w₀·ΔC₀ + wN·ΔCN。兩者都做過數值檢查： 恆等式在全部 90 個 cell 上與 scikit-learn 的 average_precision_score 相差小於 1e-9， 差值形式的殘差小於 1e-12。

reading = 0 握有 89% 的正樣本，在以正樣本加權的指標上本就佔主導， 上述佔比因此含有結構成分。移除該權重的做法是讓每棟建築各投一票： 在每棟建築內部計算兩個模型的 ROC-AUC、取差值、再計數。

每棟建築一票：未加權平均差與符號檢定 對 p = 0.5 的雙尾精確二項檢定。只有當子集內該建築同時含兩個類別時才計入。
reading = 0 是唯一在每一個 K 都由 Tree 領先的子集，效果量 +0.024 到 +0.058， 且 K = 50–400 的 p ≤ 2.5e-3。非零讀數上的效果很小（+0.003 到 +0.025），K = 50 時更是擲硬幣 （48 棟中 24 棟）—— 但方向仍然偏向 Tree，包含 K = 725，而合併後的數字在那裡說的正好相反。

數字支持的結論

  1. 01

    這個 gap 是 reading = 0 的 gap。

    依精確分解，它在 K ≤ 400 承擔了合併 PR-AUC 差距的 95–100%；而在每棟建築各投一票之後， reading = 0 是唯一每個 K 都由 Tree 領先的子集（ROC-AUC +0.024 到 +0.058，K = 50–400 的 p ≤ 2.5e-3）。分層檢定確認它是同棟建築內的排序差異（§2）。

  2. 02

    差距最大的格子是 K = 400，而 TabPFN 在那裡於零讀數上停住。

    從 K = 200 到 400，Tree 的 reading = 0 ROC-AUC 由 0.789 走到 0.862，TabPFN 則由 0.774 走到 0.779，而且 Tree 在 5 個 building seed 全勝。合併 PR-AUC 差 +0.0856 ± 0.0243，是全表最大。context 大小在每個 K 都固定在 50,000 列， 所以跨 K 改變的只有建築多樣性 —— TabPFN 在 K = 400 沒有把多出來的多樣性轉換成零讀數那半的增益， 到 725 才追上（0.857）。此處僅陳述觀察，機制尚待驗證。

  3. 03

    非零那一欄由單一棟建築決定。

    移除建築 1241 後，合併的 reading ≠ 0 gap 在每個 K 都塌到 ±0.01 以內，包含 K = 725 的那次反轉。 逐建築來看，Tree 在那裡仍然領先 48 棟中的 37 棟。

  4. 04

    兩半是不同的任務，而分界線是任意的。

    零讀數是斷供偵測：97% 的零異常位於整段皆異常的區塊內，超過 7 天的區塊有 71.9% 為異常， 而 3 小時以下的區塊只有 2–5%，且 hour-of-day 幾乎不帶資訊（45.7–51.1%）。 非零異常的主要樣態是卡住的錶與偏低的讀數（%z>3 為 3.1% 對 2.6%）。圖 1 裡那支錶被釘在 0.08 長達 240 小時 —— 與剛好為 0 是同一個故障，卻因為兩百分之一的差距被分到了另外一半。

限制與後續方向

本次分析有五項限制，依影響範圍排序如下。

  1. 非零那半的模型差距由單一棟建築決定。建築 1241 佔熱水列數的 1.4%， 卻含 52.4% 的非零異常；移除後合併 reading ≠ 0 的 ROC-AUC gap 在每個 K 都落在 ±0.01 內 （K = 725 由 −0.064 變為 −0.004）。該半的任何模型層面結論都需在排除該建築後重新確認， 後續實驗宜將其列為獨立分層。
  2. 合併指標含有可觀的跨建築成分。reading = 0 子集內 98.7% 的排序配對來自不同建築； 夏季合併 gap +0.108 對逐建築中位數 +0.018，量級相差六倍。 模型比較宜同時報告逐建築配對結果，或改用建築內分層指標。
  3. 固定 0.50 的操作點受平衡 context 的 prior shift 影響。context 先驗為 50%、 評估盛行率為 14.26%（非零半 2.12%），分數因而系統性高估： 非零子集在 0.5–0.6 箱的預測值 0.547 對實際 0.030。 reading ≠ 0 的最佳閾值落在 0.64–0.76，0.50 下的表現變化多為閾值假象。 部署前的操作點需在驗證集重調並依目標盛行率做先驗校正。
  4. 兩個子集的指標絕對值不可跨半比較。盛行率為 47.7% 對 2.12%， 無技巧 F1 上限分別為 0.646 與 0.042，相差 15 倍；lift 形式的天花板也隨盛行率變動 （1.5× 對 24×）。跨子集比較宜採 skill score、MCC 或 ROC-AUC。
  5. 季節性目前只在族群層面成立。逐建築配對檢定受限於樣本： reading = 0 兩季都可評分的建築僅 1 棟，reading ≠ 0 為 24 棟且方向符合者 10 棟（p = 0.54）。 要把季節性提升為建築內部的機制主張，需要跨年度資料以取得同一棟建築的多個冬夏配對。
